**agent_name** | **object** | Human-readable agent name, unique within your tenant. This is not the hosted agent UUID used in &#x60;/agents/{agent_id}&#x60; REST paths. If no agent with this name exists yet, a write-scoped call (&#x60;agents:write&#x60;) creates a minimal learning agent in your tenant. &#x60;POST /resolve&#x60; with only &#x60;agents:read&#x60; looks up an existing name and does not insert. Reuse the same name on resolve, observe, reinforce, and distill to target the same learning corpus. Clients conventionally namespace an agent-loop &#x60;run_id&#x60; as &#x60;&lt;agent_name&gt;:...&#x60;; if yours does, avoid the name &#x60;distill&#x60;, because &#x60;distill:&#x60; is reserved for corpus distillation run ids and every agent-loop write would be refused. |
**is_delivered** | **object** | Whether this turn&#x27;s recall was delivered in a way the turn can be credited for. A turn can receive the injection and still decline, so this decides whether the resolve is billed or released: the caller is charged for the resolve this turn consumed, never for one it did not. A warm stash reports false and is not charged even though the model saw it, because the block was resolved on an earlier turn and this turn consumed no resolve of its own. Whether that earlier turn was itself charged is that turn&#x27;s own report, not something this field asserts. Omitted means the host did not report either way, which is recorded as unknown rather than as a definite non-delivery: the credit alert separates a decline that lost credit from one that never had any to lose, and a default of false would silently file every omitting client under the second. | [optional]
**obligation_outcomes** | **object** | Obligations this turn resolved. Present on decline as well as on reinforce because the two questions are independent: a turn can produce nothing worth learning and still have closed something the shelf was owed, and a host forced to choose would either lose the closure or credit an episode it had already judged not worth crediting. Ids the run never offered are counted and dropped, never refused. | [optional]
**org_id** | **object** | Optional caller-owned organisation reference. | [optional]
**reason** | [**DeclineReason**](DeclineReason.md) | Why the turn had nothing worth learning from. |
**recall_outcome** | **object** | Why the recall earned nothing this turn, from the same closed set reinforce uses. A declined turn that was never shown its learnings is a different run from one that was shown them and did too little to be worth learning from, and different again from one shown a warm stash it can never be credited for. Sending this without &#x60;is_delivered&#x60; is enough: the flag is derived from it. Sending both with different meanings is not refused, it is reconciled in favour of this field and the disagreement is logged. | [optional]
**run_id** | **object** | The caller-owned &#x60;run_id&#x60; supplied to resolve; it must not start with &#x60;distill:&#x60;, which is reserved for distillation jobs. |
**source_framework** | **object** | Producing host/framework, used to attribute the per-host funnel. Optional; the server derives one when it is absent. &#x60;unknown&#x60; is reserved: the loop-closure funnel groups runs with no attribution under that label and excludes them from alerting, so a value equal to it is normalised to unset rather than stored as a host. | [optional]
