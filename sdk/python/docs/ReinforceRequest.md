**agent_name** | **object** | Human-readable agent name, unique within your tenant. This is not the hosted agent UUID used in &#x60;/agents/{agent_id}&#x60; REST paths. If no agent with this name exists yet, a write-scoped call (&#x60;agents:write&#x60;) creates a minimal learning agent in your tenant. &#x60;POST /resolve&#x60; with only &#x60;agents:read&#x60; looks up an existing name and does not insert. Reuse the same name on resolve, observe, reinforce, and distill to target the same learning corpus. Clients conventionally namespace an agent-loop &#x60;run_id&#x60; as &#x60;&lt;agent_name&gt;:...&#x60;; if yours does, avoid the name &#x60;distill&#x60;, because &#x60;distill:&#x60; is reserved for corpus distillation run ids and every agent-loop write would be refused. |
**context_receipt** | **object** | The host&#x27;s record of the context block as its editor accepted it, used to confirm which offered learnings the model was actually shown. A learning no receipt reports as rendered credits nothing, so a host that omits this earns no reinforcement. Send the artefact the editor produced, never the text this client emitted: an echo of what was sent asserts the very thing the receipt exists to evidence. An over-cap receipt is clipped when folded rather than refused, because refusing it would cost the run its whole reinforcement and not merely its evidence; the bound on this field is far above that clip and exists only to stop an unbounded body. | [optional]
**episode** | [**EpisodeModel**](EpisodeModel.md) | Completed episode using the same caller-owned &#x60;run_id&#x60; supplied to resolve. |
**is_delivered** | **object** | Whether this turn&#x27;s recall was delivered in a way the turn can be credited for, which is not the same question as whether the model saw something. Omit it and an absent &#x60;context_receipt&#x60; has two readings, a run that was shown its learnings and lost the evidence and a run that was never shown them at all, and only the first is a defect. A warm stash is the case where the two readings come apart: it was shown, and it reports false here, because it carries no run marker any receipt could match. NULL means the client did not say. | [optional]
**is_org_promotion_allowed** | **object** | Whether eligible learnings may be considered for organisation sharing. | [optional]
**obligation_outcomes** | **object** | Obligations this turn resolved, closed alongside the reinforcement rather than one call at a time. Every id must be one this run was offered; ids the run never offered, and ids naming a terminal state contradicting the one already held, are counted and dropped rather than refused, so one stale id cannot cost the run its entire reinforcement. An id whose requested terminal state already holds is a silent no-op. Directed and harvested obligations alike are closable here: eligibility is the offer log, not the provenance class. | [optional]
**org_id** | **object** | Optional caller-owned organisation reference. | [optional]
**recall_outcome** | **object** | Why the recall produced no receipt this turn, from a closed set. Distinguishes a resolve that timed out or failed, a stash no tool event ever showed, a warm stash that WAS shown and can never be credited, and a transcript whose format the client no longer recognises, which is the one that silently ends the whole credit path. Not every member means the model saw nothing: &#x60;stash_emitted&#x60; means it saw an earlier turn&#x27;s block. Sending this without &#x60;is_delivered&#x60; is enough: the flag is derived from it. Sending both with different meanings is not refused, it is reconciled in favour of this field, which is the more specific of the two, and the disagreement is logged. | [optional]
